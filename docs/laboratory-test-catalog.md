# Laboratory Test Catalog

The catalog uses `laboratory_test_categories`, `specimen_types`, `laboratory_tests`, `laboratory_test_components`, and `laboratory_reference_ranges`.

Categories and specimen types are configurable and soft-deleted. Tests preserve code, name, result type, unit, specimen type, fasting flag, verification flag, panel flag, and active state. Panel tests expand server-side into component request items.

Seeded catalog data is fictional demonstration data and is not a complete or hospital-approved laboratory catalog.
